# sprites

this is an old project that wandered every which way and went nowhere, but there are some interesting algorithms that were implemented. Main ones were A\* (in src/mapgenerator.c src/maputil.c), delaunay triangulation (src/delaunay.c), and separating axis theorem (in src/entitymanager.c). Otherwise, a lot of this I would redo and make simpler if I had the time and willpower. Maybe I will make something playable out of it one day.
